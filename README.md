# 📚 LibrarySphere – Smart Library Management System

A web-based Smart Library Management System developed using Python, Flask, SQLite, HTML and CSS. This project simplifies library operations through book inventory management, issue and return tracking, borrower records and data analytics.

## 🚀 Project Overview

LibrarySphere is an educational full-stack web development project designed to demonstrate how frontend technologies, backend development and database management work together.

It provides a centralized interface for managing library resources and monitoring library activities.

## ✨ Features

- 📖 Book inventory management
- ➕ Add, update and delete book records
- 🔍 Search and filter books
- 📤 Issue books to borrowers
- 📥 Return issued books
- 📅 Due-date and overdue tracking
- 📊 Dashboard with library statistics
- 📈 Popular books and analytics
- 📁 CSV data export
- 🗄️ SQLite database integration
- 📱 Responsive web interface

## ▶️ How to Run

1. Download the project notebook from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Select File → Upload notebook.
4. Upload `LibrarySphere_Full_Stack_Capstone.ipynb`.
5. Run the notebook cells in sequential order.
6. Open the generated application link to access LibrarySphere.
